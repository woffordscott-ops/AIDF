# Task

You are working in a copy of a small multi-tenant ticketing and billing service (`app/`, `tests/`, `tools/`). It is a git repository. The latest commit is a teammate's change, and its message is their description of it.

Review that change (start with `git show HEAD`, or read `review/change.diff` and `review/description.md`, which hold the same diff and description). Do not change any file.

Write a review report in plain markdown. For each finding give the file and function, what is wrong, who can do what because of it, and how serious it is. If you find nothing wrong, say so and say what you checked. End with one line: `Verdict: approve`, `Verdict: approve with comments` or `Verdict: do not approve`.
