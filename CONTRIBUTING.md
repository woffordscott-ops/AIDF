# Contributing

**External contributions are not accepted yet.** This repository is maintained by a single Change Owner, and its own changes go through the review process it describes (`core/05-review.md`), which assumes named roles and an independent Verifier. Pull requests and merge requests from outside that process will not be merged.

What you can do:

- **Use the framework** and tell us what did not work: email the maintainer (woffordscott@gmail.com) describing the situation, what you expected, and what the documents said. There is no public issue tracker yet.
- **Report a defect** in the framework or its checkers: see `SECURITY.md` if it is a security problem, otherwise email the maintainer as above.
- **Fork it.** The license (see `LICENSE`) allows it.

This page will change when contributions open. Until then, please do not spend effort on a patch for this repository.
